<h1>🎬 Netflix Homepage Clone</h1>

<p>
A responsive <strong>Netflix Homepage Clone</strong> built using <strong>HTML</strong> and
<strong>CSS</strong>. This project focuses on recreating the UI and layout of Netflix’s
landing page to strengthen front-end development fundamentals.
</p>

<h2>🧠 Purpose of This Project</h2>
<ul>
    <li>Practice semantic HTML structure</li>
    <li>Improve CSS styling and layout skills</li>
    <li>Understand Flexbox positioning</li>
    <li>Learn real-world UI cloning</li>
    <li>Build confidence in front-end development</li>
</ul>



<h2>🚀 Features</h2>
<ul>
    <li>Netflix-style navigation bar</li>
    <li>Hero section with background image</li>
    <li>Email input UI</li>
    <li>Content sections similar to Netflix landing page</li>
    <li>Footer section</li>
    <li>Hover effects</li>
    <li>Clean and structured layout</li>
</ul>


<h2>🛠️ Technologies Used</h2>
<ul>
    <li>HTML5</li>
    <li>CSS3</li>
    <li>Flexbox</li>
    <li>Google Icons</li>
</ul>
